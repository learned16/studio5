# نشر Studio5 على حسابك الشخصي في Cloudflare

التطبيق ملفات ثابتة داخل `studio5-app/public` (صفحة + Service Worker + أيقونات).
Cloudflare لا يخزن أي بيانات؛ بياناتك تبقى في جهازك (ومع Backup).

## الطريقة الأسهل (بدون توكن): ربط GitHub من لوحة Cloudflare

1. ادخل بحسابك الشخصي على dash.cloudflare.com (تأكد من اسم الحساب أعلى اليسار، مو حساب الشركة).
2. Workers & Pages ← Create ← Import a repository ← اختر `learned16/studio5`.
3. الإعدادات:
   - Production branch: الفرع اللي بيه التطبيق (حالياً `claude/zen-bell-oqcqtr`).
   - Root directory: `studio5-app`
   - Build command: `node build.mjs`
   - Deploy command: `npx wrangler deploy`
4. Deploy. يطلع لك رابط مثل `https://studio5-app.<اسمك>.workers.dev`.
   كل Push جديد ينشر تلقائياً.

## التنصيب على اللابتوب

افتح الرابط بـ Chrome أو Edge ← أيقونة التنصيب بشريط العنوان (أو القائمة ← Install Studio5).
يصير برنامج بنافذة وأيقونة خاصة ويشتغل بدون إنترنت.

## ملاحظات

- نسخة Cloudflare تحفظ على الجهاز نفسه فقط. لنقل البيانات بين الأجهزة: System ← Backup ← Restore.
- الذكاء الاصطناعي والمزامنة السحابية متوفرة بنسخة claude.ai فقط.

## التحقق بعد النشر

- افتح `https://studio5-app.<اسمك>.workers.dev` ← System ← Health: لازم يظهر «Install on this computer».
- إذا البناء ما بدأ: Workers & Pages ← studio5-app ← Settings ← Build ← تأكد أن Production branch هو `claude/zen-bell-oqcqtr` و Root directory هو `studio5-app`.

## التحكم باللابتوب من الموبايل

النشر نفسه يرفع «الخادم الوسيط» (Worker + Durable Objects، متاحة بالخطة المجانية). بعد النشر:

1. على اللابتوب: افتح موقعك ← النظام ← التحكم باللابتوب ← «نزّل المثبّت لويندوز» وشغّله.
   ينصّب Node.js إذا ما موجود، يشغّل «Studio5 Companion» بنافذة ظاهرة، ويعرض رمز اقتران من 6 أرقام.
2. على الموبايل: افتح نفس الموقع ← اللابتوب ← أدخل الرمز.
3. قارن «رقم التحقق» على الشاشتين؛ إذا متطابق اكتب `y` بنافذة اللابتوب.
4. يشتغل تلقائياً عند تشغيل الويندوز (نافذة ظاهرة — اغلقها لإيقاف التحكم).

الأمان: تشفير طرف لطرف (ECDH + AES-GCM)، حماية من إعادة الإرسال، أوامر محددة فقط (لا أوامر Shell)،
الملفات محصورة بمجلد `Documents\Studio5`، الإطفاء يحتاج تأكيد، وكل أمر يُسجّل في
`%APPDATA%\Studio5Companion\activity.log`. لإلغاء الاقتران احذف `config.json` من نفس المجلد.
لتعطيل أمر معيّن أضفه إلى `"disabled"` في `config.json` (مثلاً `["sys.shutdown"]`).

## الاختبار الشامل

- داخل التطبيق: النظام ← الاختبار الشامل ← «شغّل الاختبار التلقائي» + قائمة اختبارات الجهاز الحقيقي.
- للمطوّر: `bash tests/run-all.sh`.

## ملاحظة حول مكافح الفيروسات (مهم)

النسخة الأولى من المرافق كانت تولّد سكربت PowerShell للتحكم بالماوس والكيبورد والشاشة، وهذا نمط يحجبه
Windows Defender تلقائياً. الحل الصحيح (المطبّق الآن): المرافق يستخدم مكتبة مفتوحة المصدر معروفة اسمها
`nut-js` تنزّل ملفاتها الثنائية الجاهزة عبر `npm install` — بلا أي سكربت يُولّد أو يُترجم وقت التشغيل.
المثبّت يسوي هذا تلقائياً. إذا فشل تنصيب المكتبة، التحكم بالماوس/الكيبورد/الشاشة ينطفي ويبقى كل شي
الثاني (الملفات، البرامج، المهام) شغّال، وتگدر تعيد تشغيل المثبّت لإضافتها لاحقاً.

إذا احتجت تحدّث لابتوب منصّب عليه النسخة القديمة: احذف مجلد `%LOCALAPPDATA%\Studio5Companion` وأعد تشغيل المثبّت.

## التحديث التلقائي

- التطبيق (الموبايل واللابتوب): يفحص كل 10 دقايق وكل ما ترجعله؛ إذا أكو نسخة جديدة يعيد التحميل وحده لما تكون مو شغّال بيه.
- المرافق على اللابتوب (من النسخة 1.1.0): يحدّث نفسه من موقعك كل 30 دقيقة ويعيد تشغيل نفسه بنفس النافذة.
  من الموبايل: اللابتوب ← النظام ← «حدّث اللابتوب الآن». لإيقافه: `"autoUpdate": false` في `config.json`.
- إعادة تشغيل المثبّت ما تلغي الاقتران بعد الآن.

## تطبيق «Laptop Remote» المنفصل + الفيديو الحقيقي

- الرابط: `https://studio5-app.<اسمك>.workers.dev/remote/` ← بالآيباد/الموبايل: مشاركة ← «إضافة إلى الشاشة الرئيسية». نفس الاقتران، بدون واجهة Studio5.
- الفيديو: المرافق (1.2.0) يفتح Chrome أو Edge مخفي على اللابتوب يلتقط الشاشة بمرمّز الفيديو مال الكارت ويبثها WebRTC مباشرة
  (على نفس الواي فاي يروح مباشر بين الجهازين). إذا ما اشتغل يرجع تلقائياً للصور.
- كيبورد وماوس حقيقيين على الآيباد (Magic Keyboard / بلوتوث) يشتغلون مباشرة، والأزرار المضغوطة تبقى مضغوطة (للألعاب).
- للألعاب: خلي اللعبة «Borderless / Windowed fullscreen» حتى تنلقط بالبث.
