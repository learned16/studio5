# Drawing Coach Lite

## التعريف

ليس Canvas فارغاً ولا مكتبة فيديو. هو حلقة: **تعلم -> تدرب -> طبق -> اختبر -> راجع**. يركز في السنة الأولى على فائدة قابلة للقياس دون ادعاء حكم فني أو درجة أكاديمية نهائية.

## مكتبة البداية

Line confidence، خطوط متوازية، دوائر وأقواس، Cubes، منظور نقطة/نقطتين، سلالم، غرفة، واجهة، مشهد شارع، وتمارين رسم هندسي أساسية.

## جلسة التمرين

1. هدف مهاري واضح ووقت مقترح.
2. مثال وخطوات قصيرة.
3. Canvas ومحاولة محفوظة بـraw strokes.
4. محاولة مستقلة ثم Overlay مرجعي اختياري بعد المحاولة.
5. قياس بسيط، سجل خطأ، واقتراح محاولة لاحقة.

## القياسات المسموحة في Lite

استقامة تقريبية، توازٍ، تقارب باتجاه نقطة هروب، اكتمال الشكل، الالتزام بالوقت، وعدد المحاولات. لا يزعم النظام صحة معمارية نهائية أو جودة إبداعية بشرية.

## ربط واجب الأستاذ

Assignment يضم المطلوب والموعد والمتطلبات والملاحظات. تحول ملاحظة الأستاذ إلى عنصر عمل/تمرين علاجي ومحاولة لاحقة مرتبطة، مع مقارنة قبل/بعد عندما تتوفر.

## شرط التقنية

قبل اعتماد Stack، تختبر الكتابة بالقلم والLatency وحجم الملفات والاستعادة على MatePad الحقيقي.
