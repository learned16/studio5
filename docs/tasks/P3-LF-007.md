# P3-LF-007 - PDF, Notes, and Local Library UI

## الهدف

إكمال PDF/Notes في Phase 3 عبر Note Core دائم وواجهة مكتبة تجريبية مستقلة تفتح PDF المحلي وتحفظ الملاحظات والمفضلة والحديثة.

## المتطلبات المرتبطة

- `S5-FR-005C`
- `S5-DATA-PDF-001`
- المرجع السلطوي: Study يشمل PDF والدفاتر والملاحظات والبحث والمفضلة والحديثة، والأصل immutable.

## النطاق

### Core

- `Note` عامة مرتبطة بـSubject، وبـLecture أوFileArtifact/FileVersion اختيارياً.
- ملاحظة PDF تحمل `pageNumber` اختيارياً، ولا تعدّل bytes الملف.
- إنشاء وتحديث وقائمة الملاحظات.
- فهرسة Note في Search وإتاحتها للمفضلة والحديثة.
- Schema v8 ومهاجرة v7 -> v8 مختبرة.

### Prototype UI

- Route مستقلة: `/library/`.
- رفع PDF محلياً إلى FileArtifact/Content Store.
- فتح PDF داخل الواجهة مع زر فتح خارجي احتياطي.
- قائمة ملفات محلية.
- ملاحظة نصية مرتبطة بالملف ورقم صفحة اختياري.
- Draft recovery محلي قبل الحفظ.
- Search وFavorites وRecent عبر Core، لا عبر منطق شاشة خاص.
- Offline cache للأصول البرمجية؛ PDF المرفوع يبقى في IndexedDB.

## خارج النطاق

- لا تعديل بالقلم فوق PDF في هذه الدفعة؛ Ink وNotebook يبقيان وحدة مستقلة.
- لا استخراج نص PDF أو OCR.
- لا رفع سحابي ولا Sync.
- لا AI.
- لا تغيير واجهة Capture أو Closeout.
