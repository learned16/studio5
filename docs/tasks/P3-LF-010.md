# P3-LF-010 - Internal PDF.js Viewer

## الهدف

عرض ملفات PDF المحفوظة داخل مكتبة Studio5 على MatePad حتى عندما لا يوفر Huawei WebView عارض PDF
مدمجاً. يبقى الملف الأصلي immutable، وتكون طبقة العرض قابلة للاستبدال من دون تغيير Core أو البيانات.

## المشكلة المثبتة

- اختيار PDF وحفظه وتنزيله يعمل.
- العرض الحالي يعتمد على `iframe` مع `blob:` URL.
- Huawei WebView يستطيع تنزيل الـBlob لكنه لا يرسم PDF داخل `iframe`.

## Requirement

- `S5-UX-PDF-VIEWER-001`

## النطاق

- إضافة PDF.js محلياً، وليس من CDN.
- استبدال `iframe` بطبقة عرض Canvas مستقلة داخل Library.
- عرض صفحة واحدة في كل مرة لتقليل الذاكرة.
- السابق، التالي، رقم الصفحة، Zoom، وFit width.
- إبقاء «فتح منفصل» والتنزيل كخيار احتياطي.
- إبقاء PDF الأصلي وبيانات FileArtifact وNote من دون تغيير.
- Cache ملفات تشغيل PDF.js الأساسية، وCache عند الطلب للموارد الإضافية.

## المخاطر

- ملفات PDF كبيرة قد تستهلك ذاكرة عالية؛ لذلك تُعرض صفحة واحدة وتُحدد دقة الجهاز.
- بعض ملفات الخطوط تحتاج CMaps/standard fonts؛ تُحزم محلياً.
- نجاح الاختبارات الآلية لا يغلق Device Gate.

## Replace / Retire

`library/pdf-viewer.mjs` Adapter تجريبي. يمكن استبداله بعارض آخر مع بقاء عقد `open(bytes)` وCore
والملفات الأصلية كما هي.
