# P0-INK-CANVAS-EXPAND — تكبير مساحة الرسم

## الهدف

تكبير مساحة الرسم المرئية في مختبر القلم على MatePad، مع إبقاء سلوك القلم والممحاة والتحريك والحفظ كما هو، وإضافة وضع تركيز يمنح اللوحة أكبر مساحة ممكنة عند الحاجة.

## قرار المستخدم

القرار الأحدث هو تكبير شاشة الرسم، وليس تصغيرها.

## النطاق

- تقليل المساحة التي تستهلكها الترويسة وشريط الأدوات وشريط الحالة.
- إبقاء شريط الأدوات في صف أفقي قابل للتمرير بدل تمدده إلى عدة صفوف.
- تقليل هامش ملاءمة الورقة داخل مساحة الرسم.
- إضافة زر واضح لتفعيل/إلغاء وضع تركيز موسّع.
- إعادة قياس الـCanvas وملاءمة الورقة بعد تغيير الوضع.
- تحديث Cache الـPWA حتى تصل الواجهة الجديدة إلى الجهاز.

## خارج النطاق

- لا تغيير لنموذج بيانات الرسم أو Schema التخزين.
- لا تغيير لمنطق القلم أو الممحاة أو Palm rejection.
- لا إضافة PDF أو مواد أو ذكاء اصطناعي.
- لا حذف أو تعديل للرسومات الحالية.

## معايير القبول

1. مساحة الرسم الافتراضية أكبر من النسخة السابقة على شاشة التابلت.
2. شريط الأدوات لا يلتف إلى أكثر من صف، ويمكن تمريره أفقياً.
3. زر «توسيع الرسم» يخفي العناصر الثانوية ويزيد مساحة الـCanvas.
4. زر إلغاء وضع التركيز يعيد الواجهة كاملة.
5. الورقة تُعاد ملاءمتها بعد التبديل أو تدوير الجهاز.
6. القلم والممحاة والتحريك والحفظ والاستعادة والتصدير تبقى عاملة.
7. Build وLint وType Check والاختبارات الحالية تنجح.

## Rollback

الرجوع عن Commit هذه المهمة يعيد تخطيط الواجهة وإصدار Cache السابق، ولا يمس بيانات الرسم المخزنة.
