# P3-LF-008 - MatePad PDF Picker Compatibility

## المشكلة

المستخدم لا يستطيع اختيار PDF من واجهة `/library/` على الجهاز. حقل الملف
كان شفافاً ومعطلاً عن استقبال المؤشر (`pointer-events: none`) ويعتمد على
سلوك `label` غير المضمون في بعض WebViews.

## النطاق

- إبقاء `input[type=file]` الحقيقي فوق مساحة الاختيار ليحصل على اللمس مباشرة.
- عرض اسم الملف المختار وحجمه قبل الحفظ.
- تعطيل زر الحفظ حتى اختيار ملف صالح.
- إظهار تنبيه إرشادي إذا لم يصل حدث اختيار الملف.
- عدم تغيير Schema أو FileArtifact أو IndexedDB أو حد 50MB.
