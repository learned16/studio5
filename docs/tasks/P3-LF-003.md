# P3-LF-003 - Quick Lecture Capture UI

## الهدف

إنشاء واجهة مستقلة وخفيفة لالتقاط نقاط المحاضرة فورياً وربطها بالسياق الأكاديمي العام داخل Studio5 Core، من دون المساس بواجهة الرسم أو إدخال PDF أو الذكاء الاصطناعي.

## Requirement IDs

- `S5-FR-005`
- `S5-FR-005B`
- `S5-DATA-002`

## الملفات المسموحة

- `prototype/p3-lecture-capture-web/**`
- `docs/tasks/P3-LF-003.md`
- `PROJECT_STATUS.md`
- `docs/ACCEPTANCE_TESTS.md`

لا تتغير عقود Core أو Schema v5 في هذه المهمة.

## داخل النطاق

- سطح اختبار مستقل عن P0 Ink.
- سياق محاضرة تجريبي عام بمعرفات مستقرة، من دون تثبيت أسماء مواد السنة الأولى في Core.
- خمسة أنواع Capture معتمدة:
  - ما فهمت.
  - مهم.
  - تكليف.
  - سؤال للأستاذ.
  - ملاحظة أستاذ.
- إدخال سريع يدعم اللمس ولوحة المفاتيح.
- حفظ Local-first في IndexedDB عبر Studio5 Core.
- عرض آخر Captures وعدد عناصر Lecture Inbox غير المنظمة.
- استمرار العمل دون شبكة بعد أول فتح.
- نشر خاص على Sites للتجربة.

## خارج النطاق

- Closeout UI وتحويل Capture إلى Task؛ يأتيان في P3-LF-004.
- PDF وInk وDrawing Coach وAI.
- Search وFavorites/Recent.
- الحذف أو التعديل الصامت للـCapture الخام.
- المزامنة متعددة الأجهزة.

## معايير القبول

1. يحفظ كل نوع من الأنواع الخمسة بالنوع والنص والسياق الصحيح.
2. لا يسمح بحفظ نص فارغ.
3. إعادة الفتح تعرض Captures المحفوظة من IndexedDB.
4. ترتيب القائمة الأحدث أولاً، بينما تبقى عقود Core حتمية كما هي.
5. يعرض Inbox count المشتق ولا ينشئ Collection جديدة.
6. لا يعدل P0 Ink أو بياناته أو رابط نشره.
7. Build وLint وType Check واختبارات الواجهة وCore وInk regression تنجح.
8. الفرع يرفع مستقلاً ولا يدمج في `main`.

## Rollback
