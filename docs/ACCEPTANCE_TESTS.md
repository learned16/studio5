# Acceptance Tests

## Prototype P0 - Ink, Save, Recovery, Export

- [ ] القلم والممحاة يعملان على MatePad 11.5 PaperMatte.
- [ ] يحفظ الضغط عند توفره ولا يفشل عند غيابه.
- [ ] لا ترسم اللمسات العرضية أثناء الكتابة (Palm rejection).
- [ ] Zoom وPan لا يتلفان موضع stroke.
- [ ] Autosave يعمل أثناء الرسم.
- [ ] بعد Force Kill وإعادة الفتح، تعود المحاولة الأخيرة بسلامة كاملة.
- [ ] يعاد تحميل الخطوط نفسها بلا انزياح أو تلف.
- [ ] يقاس latency/الذاكرة وحجم بيانات strokes على جهاز حقيقي.
- [ ] يصدر نموذج تجريبي مع manifest مفهوم.

## Core acceptance

- [ ] يمكن إنشاء Year/Semester/Subject دون اعتماد داخلي على اسم مادة.
- [ ] يعمل Today والمهام والمحاضرات والدفاتر من دون شبكة.
- [ ] File intake لا يبدل الأصل بلا موافقة ويكشف التكرار بالـhash.
- [ ] Lecture Capture يتحول في Closeout إلى عناصر منظمة مرتبطة.
- [ ] Backup ثم Restore يعيد الملفات والملاحظات والرسومات مع تحقق العدّ/الـmanifest.
- [ ] كل Migration تملك اختباراً ومسار فشل مفهوم.

## Drawing Coach Lite

- [ ] تمرين يملك هدفاً وخطوات ووقتاً ومحاولة محفوظة.
- [ ] Overlay لا يظهر افتراضياً أثناء المحاولة المستقلة.
- [ ] يعرض القياسات البسيطة ومحدوديتها بوضوح.
- [ ] تربط ملاحظة أستاذ بمحاولة أو تمرين متابعة.
