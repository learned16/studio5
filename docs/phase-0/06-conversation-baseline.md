# Studio5 — المخطط الأساسي المستخرج من محادثة «تطبيق دراسة هندسي»

**الحالة:** مرجع متطلبات مؤكد من مالك المشروع  
**التاريخ:** 2026-07-24  
**طبيعة المصدر:** سياق محادثة منقول، أكّد المستخدم أنه المخطط الأساسي الذي يُرجع إليه عند الحاجة.

## 1. التعريف النهائي

Studio5 نظام شخصي طويل الأمد لطالب هندسة تقنيات العمارة والبناء. يبدأ كأداة دراسة ورسم للسنة الأولى، ثم يتوسع سنةً بعد سنة فوق نفس البيانات حتى مشروع التخرج والعمل المهني.

ليس الهدف:

- منصة طلاب.
- شبكة اجتماعية.
- نظام جامعة.
- متجرًا أو خدمة اشتراك.
- Chat بواجهة جديدة.

الهدف:

> تنظيم الدراسة، إنقاذ الفهم، تدريب المهارات الهندسية، حفظ ملاحظات الدكاترة والأخطاء والقرارات، وربط المعرفة بالمشاريع والعمل العملي.

## 2. القواعد الثابتة

1. مستخدم واحد في المرحلة الحالية.
2. Local-first وOffline للوظائف الأساسية.
3. البيانات والملفات والذاكرة ملك المستخدم وقابلة للتصدير والاستعادة.
4. لا حذف أو دمج أو تأجيل صامت لميزة أو قرار معتمد.
5. التخطيط يمتد لخمس سنوات، والتنفيذ الحالي للسنة الأولى فقط.
6. لا Hardcoding لمنطق المواد بأسمائها.
7. المواد تُفعّل قدراتها عبر Subject Profiles وCapability Packs.
8. كل كيان دائم يملك Stable ID.
9. قواعد البيانات والصيغ قابلة للترقية عبر Versioned Migrations.
10. ملفات PDF الأصلية وملفات التسليم المجمدة لا تتغير بصمت.
11. الذكاء يساعد ولا يستبدل تفكير الطالب أو حكم الأستاذ والمختص.
12. أي نتيجة هندسية حساسة تُعرض بوصفها تعليمية وتحتاج تحققًا.
13. تطوير Studio5 لا يجوز أن يسرق وقت الدراسة.
14. لا يبدأ كود المنتج قبل Prototype القلم وPDF والحفظ والاستعادة.

- البرامج الهندسية.

### الهاتف

- Capture سريع.

- التحكم بالـPC لاحقًا.

ثم تتحول العناصر إلى مهام ومراجعات وفجوات فهم.

### Daily Study Execution

### Exam Mastery

## 7. Understanding Rescue

`ما فهمت` ليس Chat عامًا.

### التدفق

```text
التقاط نقطة الغموض
→ حفظ الصفحة أو السؤال أو الرسم والسياق
→ تحديد نوع المشكلة
→ تشخيص الأساس الناقص
→ اختيار طريقة شرح
→ مثال أو تطبيق
→ تحقق من الفهم
→ سؤال دقيق للأستاذ عند الحاجة
→ تسجيل جوابه
→ إغلاق الفجوة أو إبقاؤها مفتوحة
```

### أنواع المشكلة

- مصطلح.
- فكرة.
- سبب الاستخدام.
- خطوة حسابية.
- قانون.
- رسم أو مخطط.
- تطبيق.
- علاقة بين مفهومين.
- كلام الأستاذ نفسه.
- أساس سابق مفقود.

### أنماط الشرح

- مبسط.
- بصري.
- عملي مرتبط بالعمارة أو الموقع.
- أكاديمي.
- خطوة بخطوة.
- من الأساس السابق فقط.

### مستويات الفهم

- غير مفهوم.
- فهمت الشرح.
- طبقت بمساعدة.
- طبقت وحدي.
- طبقت تحت الوقت.
- أستطيع شرحه.

لا تُغلق الفجوة بمجرد الضغط على «فهمت» إذا لم يوجد تحقق، إلا بقرار يدوي واضح.

## 8. Shared Ink وPDF وNotebook

### PDF

- الأصل Immutable.
- الحبر طبقة مستقلة.
- ملاحظة جانبية مرتبطة بالصفحة دون الكتابة فوق الأصل.
- Last page/position.
- Export لنسخة مشروحة.

### Notebook

- دفاتر رئيسية وفرعية.
- صفحات Blank، Ruled، Grid، Dot، Isometric، وهندسية.
- Split View مع PDF.
- Autosave وCrash Recovery.

### Shared Ink Model

يشترك في:

- Stroke schema.
- Brush semantics.
- Layers.
- Eraser.
- Selection.
- Undo/Redo.
- Serialization.
- Recovery.
- Coordinate transforms.

لا يلزم فرض Renderer واحد على Android وWindows والويب إذا أضعف جودة القلم.

## 9. Drawing Coach

مدرب الرسم ليس Canvas ولا مكتبة فيديوهات.

### الحلقة

```text
Learn → Train → Apply → Test → Review
```

### المسارات

1. التحكم بالقلم والخط.
2. الأشكال والحجوم.
3. منظور نقطة ونقطتين.
4. الرسم المعماري: Plans/Elevations/Sections/Scales/Dimensions.
5. الرسم الهندسي والوصفية.
6. الرسم الحر المعماري.

### جلسة التمرين

1. الهدف.
2. شرح بصري قصير.
3. مثال صحيح وخاطئ.
4. إحماء.
5. محاولة موجهة.
6. محاولة مستقلة.
7. تقييم قابل للقياس.
8. تمرين علاجي.
9. إعادة محاولة.
10. حفظ التقدم.

### القياسات الأولى

- Straightness.
- Parallelism.
- Perpendicularity.
- Angles.
- Proportions.
- Symmetry عند الحاجة.
- Vanishing-point convergence.
- انتظام المسافات.
- Completion.
- Time.
- Attempts وUndo.

لا يدعي تقييم الإبداع أو الجمال المعماري في النسخة الأولى.

### Assignment Mode

واجب الدكتور يتحول إلى:

```text
تحليل المطلوب
→ تحديد المهارات
→ اختبار تشخيصي
→ خطة تدريب
→ محاولة موجهة
→ محاولة مستقلة
→ تقييم
→ علاج الخطأ
→ اختبار زمني
→ Checklist تسليم
→ ملاحظة الدكتور
→ Before/After
```

### سجل الأخطاء

يحفظ:

- الخطأ.
- أين ظهر.
- عدد مرات التكرار.
- السبب المحتمل.
- التمرين العلاجي.
- حالة التحسن.
- عودة الخطأ بعد فترة.

## 14. الذكاء الاصطناعي

### في السنة الأولى

- اختياري.
- لا يمنع العمل عند غياب الإنترنت أو الرصيد.
- نموذج واحد مناسب افتراضيًا.
- مصادر وسياق واضحان.
- لا تعديل صامت للبيانات.

### AI Council

محفوظ للرؤية المستقبلية، وليس في المسار الحرج:

- قرارات عالية الأثر.
- مشروع التخرج.
- مراجعة نهائية.
- بعد موافقة وتقدير كلفة.

### الميزانية

- Normal منخفض.
- Heavy لفترة أكاديمية.
- Exceptional قد يصل إلى 100 دولار مؤقتًا وبموافقة.
