# Studio5 — Year One Master Specification

**الإصدار:** 0.1 Draft  
**الجمهور:** مالك المنتج والتنفيذ والاختبار  
**مبدأ المنتج:** مساحة دراسة ورسم موثوقة لطالب العمارة، تبدأ من العمل اليومي وتظل بياناتها صالحة للتوسع في السنوات اللاحقة.

> **تنبيه مصالحة:** هذه المسودة كُتبت قبل استلام المخطط الأساسي الموسع في
> `06-conversation-baseline.md`. لا تُعتمد كـMaster Specification نهائية قبل
> إغلاق القرارات الواردة في `07-scope-reconciliation.md`.

## 1. تعريف النجاح

تنجح نسخة السنة الأولى عندما يستطيع الطالب، على جهازه الأساسي ومن دون إنترنت:

1. معرفة محاضراته ومهامه لليوم.
2. فتح مادة أو محاضرة والوصول إلى ملفاتها بسرعة.
3. استيراد PDF والكتابة فوقه بقلم سلس دون تعديل الأصل.
4. إنشاء Notebook والرسم صفحة بصفحة.
5. إغلاق المحاضرة مع حفظ الملاحظات والإجراءات التالية.
6. إغلاق التطبيق أو تعرضه لانقطاع مفاجئ ثم استعادة العمل دون فقد جوهري.
7. تصدير كل بياناته واستعادتها إلى تثبيت نظيف.
8. استخدام تمارين Drawing Coach بقياسات واضحة لا تدّعي حكمًا بشريًا.

## 2. المستخدم والمنصات

### 2.1 المستخدم الأساسي

طالب عمارة واحد. لا توجد في V1 أدوار أستاذ أو فريق أو مؤسسة.

### 2.2 أدوار المنصات المقترحة

| المنصة | الدور الأساسي |
|---|---|
| Huawei MatePad | الرسم، Notebook، PDF annotation، المحاضرة اليومية |
| Windows | تنظيم الملفات، القراءة، المهام، التصدير والاستعادة |
| الهاتف | Today، المهام، القراءة السريعة، الالتقاط إلى Inbox |

التكافؤ الكامل بين المنصات ليس افتراضًا. تُثبت القدرات النهائية بعد Prototype.

## 3. تقسيم النطاق

### 3.1 Starter — قبل/عند دخول الجامعة

- إعداد السنة والفصل والمواد.
- الجدول والمحاضرات وToday.
- المهام والتقويم الداخلي.
- Inbox وFavorites وRecent.
- إدارة الملفات وPDF وتصنيفها.
- كشف التطابق التام للملفات.
- Notebook صفحة بصفحة.
- طبقة Ink مستقلة فوق PDF.
- Autosave وCrash Recovery.
- Lecture Capture وCloseout.
- Offline للوظائف الأساسية.
- بحث في metadata والملاحظات النصية.
- Full Export/Restore.
- Backup واضح الحالة.
- Drawing Coach Lite بتمارين وقياسات محدودة.

### 3.2 بقية السنة الأولى

- مزامنة مستمرة متعددة الأجهزة.
- واجهة كشف وحل التعارضات.
- توسيع فهرسة نص PDF.
- سجل نسخ الملفات المتقدم.
- تحليلات إضافية صادقة لـDrawing Coach.
- تحسين قدرات الهاتف وWindows وفق الاستخدام الفعلي.

### 3.3 خارج نطاق السنة الأولى

- تقييم معماري ذكي يدّعي أداء الأستاذ.
- OCR شامل لكل الكتابة اليدوية.
- تعاون لحظي متعدد المستخدمين.
- Marketplace أو Plugin Engine عام.
- Microservices.
- إدارة مؤسسة أو صفوف وأساتذة.
- تعديل محتوى PDF الأصلي.

## 4. نموذج المعلومات

كل كيان دائم يحتوي، كحد أدنى، على:

- `id` ثابت.
- `createdAt` و`updatedAt`.
- `schemaVersion` أو إصدار مكافئ عند الحاجة.
- حالة حذف آمن عند انطباقها.

### 4.1 الكيانات الأساسية

| الكيان | الغرض | أهم العلاقات |
|---|---|---|
| AcademicYear | السنة الأكاديمية | يحتوي Terms |
| Term | الفصل | يحتوي Subjects وScheduleEntries |
| Subject | المادة | ترتبط بمحاضرات، مهام، ملفات ودفاتر |
| ScheduleEntry | موعد متكرر | يولّد/يربط LectureSession |
| LectureSession | جلسة محاضرة فعلية | مادة، وقت، Capture، Closeout، ملفات |
| Task | إجراء مطلوب | مادة اختيارية، موعد، حالة، أولوية |
| CalendarEvent | حدث غير المهمة | تاريخ/وقت، مادة اختيارية |
| Asset | وصف ملف | نسخة ملف، hash، MIME، حجم، اسم |
| AssetLink | ربط ملف بسياق | مادة/محاضرة/صفحة/Inbox |
| Notebook | دفتر | مادة اختيارية، Pages |
| NotebookPage | صفحة | ترتيب، خلفية، InkLayer |
| PdfDocument | مرجع PDF | Asset أصلي، page metadata |
| InkDocument | حبر مستقل | target + InkStrokes |
| InkStroke | ضربة قلم | نقاط، ضغط، وقت، أداة، لون، سماكة |
| TextNote | ملاحظة نصية | سياق مادة/محاضرة/صفحة |
| InboxItem | عنصر غير مصنف | ملف/ملاحظة/رابط داخلي |
| Favorite | إشارة مفضلة | target polymorphic |
| CoachExercise | تعريف تمرين | قواعد وقياسات |
| CoachAttempt | محاولة | strokes، وقت، نتائج قابلة للتفسير |
| BackupRecord | سجل نسخة | وقت، وجهة، نتيجة، checksum |
| ExportManifest | وصف حزمة تصدير | الإصدارات والملفات والـhashes |

### 4.2 قواعد الملفات

- الأصل Immutable.
- يُحسب hash عند الاستيراد.
- إذا تطابق hash والحجم مع ملف موجود، يُعرض خيار ربط الموجود أو استيراد نسخة منطقية؛ لا حذف تلقائي.
- الاسم والمجلد ليسا هوية الملف.
- نقل الملف بين التصنيفات يغير الروابط/metadata وليس bytes الأصلية بلا ضرورة.

### 4.3 قواعد الحبر

- إحداثيات الحبر مستقلة عن دقة الشاشة ومربوطة بمساحة الصفحة.
- stroke يحمل points مرتبة وبيانات الضغط المتاحة.
- حفظ stroke لا ينتظر نهاية جلسة طويلة.
- تغيير zoom/rotation لا يغير البيانات الأصلية للـstroke.
- Undo/Redo داخل جلسة التحرير، مع حفظ نتيجة مستقرة قابلة للاستعادة.

## 5. الوحدات والشاشات

### 5.1 Onboarding

**الهدف:** الوصول إلى نظام صالح للاستخدام بأقل إعداد.

**الوظائف:**

- إنشاء سنة وفصل.
- إنشاء المواد يدويًا.
- اختيار الجهاز الأساسي ودور النسخ الاحتياطي.
- توضيح Local-first وما الذي يُحفظ سحابيًا.

**معيار الخروج:** تظهر شاشة Today حتى لو لم يُضف المستخدم جدولًا كاملًا.

### 5.2 Today

تعرض:

- التاريخ.
- محاضرات اليوم مرتبة زمنيًا.
- المهام المستحقة والمتأخرة.
- آخر العناصر المفتوحة.
- زر Capture سريع.
- حالة Offline/Backup دون رسائل مخيفة أو غامضة.

لا تتحول Today إلى لوحة تحكم مزدحمة. الإجراء الأساسي يجب أن يكون قابلًا للوصول بلمسة أو اثنتين.

### 5.3 المواد

لكل مادة:

- اسم، رمز اختياري، لون، مدرس اختياري.
- محاضرات.
- مهام.
- ملفات.
- دفاتر.
- Recent خاص بالمادة.

حذف المادة لا يحذف ملفاتها نهائيًا مباشرة؛ يُظهر أثر الحذف ويتيح الاستعادة.

### 5.4 الجدول والمحاضرة

**Schedule:** مواعيد متكررة بحسب أيام الفصل.  
**Lecture Session:** حدث فعلي يمكن أن يحمل اختلافًا عن الموعد الأصلي.

#### بدء المحاضرة

- من Today أو المادة أو الجدول.
- يعرض آخر ملف/دفتر للمادة واقتراح إنشاء صفحة جديدة.
- يسجل وقت البدء اختياريًا دون مراقبة مخفية.

#### Lecture Capture

أثناء المحاضرة يمكن:

- فتح PDF مرتبط.
- إنشاء/فتح صفحة Notebook.
- كتابة ملاحظة نصية.
- إضافة مهمة بسرعة.
- إدخال ملف/صورة إلى Inbox وربطها لاحقًا.

#### Closeout

عند الإغلاق يعرض:

- ما تم إنشاؤه أو تعديله.
- ملاحظات تحتاج تصنيفًا.
- مهام أو مواعيد تالية.
- حقل ملخص قصير اختياري.

يجب إمكان التخطي دون فقد العمل.

### 5.5 المهام والتقويم

حالات المهمة:

- Inbox/غير مصنفة.
- Planned.
- In Progress.
- Done.
- Cancelled.

الحد الأدنى للحقول:

- العنوان.
- المادة اختيارية.
- due date/time اختياري.
- الأولوية اختيارية.
- ملاحظات وروابط إلى ملفات/صفحات.

لا يوجد تكامل إلزامي مع تقويم خارجي في Starter.

### 5.6 الملفات وPDF

الوظائف:

- استيراد ملف.
- تصنيف وربط بمادة أو محاضرة.
- عرض PDF.
- فتح آخر موضع قراءة.
- إضافة طبقة حبر.
- Favorites وRecent.
- كشف النسخ المتطابقة.
- إظهار الحجم والنوع وتاريخ الاستيراد.

حالات الخطأ المطلوبة:

- ملف غير مدعوم.
- PDF تالف أو محمي.
- مساحة محلية غير كافية.
- انقطاع الاستيراد.
- ملف كبير يسبب ضغط ذاكرة.

### 5.7 Notebook

- إنشاء دفتر باسم ومادة اختيارية.
- صفحات مرتبة.
- إضافة/حذف/تكرار/إعادة ترتيب الصفحة.
- خلفية بيضاء أو grid أو dot أو template معتمد.
- Pen، eraser، selection إن اجتاز Prototype.
- zoom/pan ومنع اللمسات العرضية وفق قدرات الجهاز.
- صورة مصغرة للصفحات تُحدّث دون تعطيل الرسم.

### 5.8 البحث والتنظيم

يدخل في Starter:

- أسماء المواد.
- أسماء الملفات وmetadata.
- عناوين المهام.
- الملاحظات النصية.
- عناوين الدفاتر.

لا يدخل افتراضيًا:

- OCR للكتابة اليدوية.
- بحث بصري داخل الرسومات.
- استخراج شامل لكل PDF قبل التحقق من الأداء.

### 5.9 Inbox وFavorites وRecent

- Inbox يستقبل العناصر غير المصنفة ويعرض عددها.
- Favorites روابط ولا تنسخ الأصل.
- Recent يحسب من آخر فتح فعلي ويتيح إزالة عنصر من القائمة دون حذفه.

### 5.10 Backup، Export، Restore

#### Backup

- حالة: لم يُفعّل، جارٍ، ناجح، فشل، يحتاج انتباه.
- يعرض وقت آخر نسخة ناجحة.
- الفشل لا يمنع العمل المحلي.
- Retry واضح.
- لا يُسمى Sync إذا لم يكن مزامنة ثنائية الاتجاه.

#### Full Export

الحزمة تشمل:

- قاعدة البيانات/السجلات المنظمة.
- الملفات الأصلية.
- الحبر.
- manifest بإصدارات الصيغ.
- hashes للتحقق.

#### Restore

- فحص الحزمة قبل التغيير.
- إظهار المساحة المطلوبة.
- عدم استبدال بيانات حالية بصمت.
- خيار الاستعادة إلى مساحة نظيفة أولًا في V1.
- تقرير نهائي بالأعداد والأخطاء.

### 5.11 Drawing Coach Lite

كل تمرين يعرّف:

- الهدف.
- التعليمات.
- الأدوات المتاحة.
- الحد الزمني إن وجد.
- القياسات المحسوبة.
- تفسير بسيط للنتيجة.

القياسات الأولية الممكنة:

- استقامة خط بالنسبة لتقريب هندسي معلوم.
- توازي خطين.
- إغلاق شكل.
- تقارب خطوط نحو نقطة تلاشي.
- الزمن.
- عدد المحاولات وUndo.

يمنع:

- إعطاء درجة «جودة معمارية» غير قابلة للتفسير.
- الادعاء بأن النتيجة بديل عن تقييم الأستاذ.
- مقارنة المستخدمين دون موافقة صريحة.

## 6. المتطلبات غير الوظيفية

### 6.1 الموثوقية

- لا يفقد الانقطاع المفاجئ أكثر من نافذة الحفظ المعتمدة.
- عمليات الاستيراد والاستعادة إما تكتمل أو تترك حالة قابلة للتشخيص والتنظيف الآمن.
- migrations قابلة للاختبار على نسخة بيانات حقيقية.

### 6.2 الأداء

الأرقام النهائية تُثبت بالـPrototype، لكن يجب قياس:

- تأخر الحبر المرئي.
- dropped/coalesced pointer events.
- زمن فتح PDF صغير وكبير.
- استهلاك الذاكرة.
- زمن autosave.
- استقرار جلسة رسم طويلة.

### 6.3 الخصوصية

- البيانات محلية افتراضيًا.
- السحابة اختيارية وموضحة.
- لا telemetry للمحتوى أو strokes دون موافقة صريحة.
- أسرار الدخول لا تدخل حزمة تصدير نصية مكشوفة.

### 6.4 قابلية الوصول والاستخدام

- أهداف لمس مناسبة.
- تباين مقروء.
- دعم اتجاه RTL للنص العربي.
- لا تعتمد الحالة على اللون وحده.
- إجراءات الحذف والاستعادة واضحة.

### 6.5 التطور

- versioned migrations.
- versioned export format.
- stable IDs.
- حدود وحدات تمنع ارتباط الرسم بالتخزين السحابي مباشرة.
- اختبارات بيانات رجعية عند كل تغيير schema.

## 7. حالات النظام

يجب تصميم كل شاشة رئيسية للحالات التالية:

- Empty.
- Loading.
- Ready.
- Offline.
- Partial failure.
- No storage.
- Permission denied.
- Corrupt input.
- Recovery available.

4. Vertical Slice: مادة → محاضرة → PDF/Notebook → Autosave → Restore.
5. Core التنظيمي.
6. Offline وLecture Workflow.
7. Export/Restore وBackup.
8. Drawing Coach Lite.
9. Hardening واختبارات فقد البيانات.
10. مزامنة متعددة الأجهزة كتوسعة مستقلة بعد استقرار الأساس.
