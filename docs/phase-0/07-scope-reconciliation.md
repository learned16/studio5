# Studio5 — مصالحة نطاق السنة الأولى

**الحالة:** يحتاج اعتمادًا قبل Freeze  
**السبب:** توجد رؤيتان صحيحتان لكن بمستويين مختلفين من العمق:

1. مسودة Starter تقنية ضيقة هدفها الوصول السريع إلى نظام موثوق.
2. مخطط السنة الأولى الموسع الذي يشمل جميع المواد، التفوق، Drawing Coach، Understanding Rescue، والمشاريع.

## 1. نقاط الاتفاق

- Core دائم وقابل للتوسع.
- MatePad هو جهاز القلم المرجعي.
- Offline والحفظ والاستعادة شروط أساسية.
- PDF الأصلي لا يُعدّل.
- القلم وPDF يحتاجان Prototype قبل اختيار التقنية.
- لا يبدأ التكامل العميق مع PC أو BIM في الإطلاق الأول.
- لا تُحذف الرؤية المستقبلية.

## 2. نقاط التعارض التي تحتاج صياغة نهائية

### R-001 — معنى «نسخة السنة الأولى»

**المسودة الضيقة:** Starter قبل الجامعة خلال 12–14 أسبوعًا.  
**المخطط الموسع:** كل أدوات مواد السنة الأولى والتفوق والمدرب والمشاريع.

**التوصية:**

- `University Starter`: أول نسخة يومية مستقرة.
- `Year-One Complete`: اكتمال الحزم المتخصصة خلال السنة الأولى.

كلاهما جزء من نفس Studio5 Core.

### R-002 — الذكاء في أول نسخة

**الخطر:** Understanding Rescue من دون AI قد يكون محدودًا، ومع AI قد يصبح اتصال الإنترنت شرطًا.

**التوصية:**

- تسجيل فجوة الفهم والسياق والأسئلة يعمل Offline.
- الشرح السحابي اختياري ومصدره ظاهر.
- يوجد Queue للشرح عند عودة الاتصال.
- لا يُعتبر الذكاء مصدر الحقيقة ولا يعدل بيانات الطالب بصمت.

### R-003 — Drawing Coach

**الخطر:** بناء مدرب متقدم قبل إثبات جودة Ink.

**التوصية:**

- Prototype Ink أولًا.
- Drawing Coach Lite يبدأ بالتمارين والقياسات الهندسية القابلة للإثبات.
- النقد الفني المتقدم يبقى في Roadmap.

### R-004 — المزامنة

**المخطط القديم:** مزامنة مبكرة بين MatePad وWindows والهاتف.  
**المراجعة الهندسية:** المزامنة الكاملة خطر مبكر.

**التوصية:**

1. Local database.
2. Full Export/Restore.
3. Optional cloud backup.
4. Sync Beta.
5. اعتماد المزامنة اليومية بعد اختبارات التعارض والاستعادة.

### R-005 — تكافؤ الأجهزة

**التوصية:**

- تكافؤ البيانات إلزامي.
- التدفقات الأساسية تصل تدريجيًا.
- لا نشترط Ink كاملًا على الهاتف والويب.
- Windows يحصل مبكرًا على إدارة وقراءة وBackup، وليس بالضرورة كل قدرات القلم.

### R-006 — مدة التنفيذ

المحتوى الموسع أكبر من نافذة 12–14 أسبوعًا.

**التوصية:**

- النافذة الأولى تستهدف University Starter.
- بقية Year-One Complete تُنجز عبر دفعات بعد الاستخدام الحقيقي.
- لا يدخل أي جزء جديد إذا الحفظ والاستعادة والقلم غير مستقرة.

## 3. النطاق المقترح لـUniversity Starter

### إلزامي

- السنة والفصل والمواد.
- الجدول وToday.
- المهام والمواعيد.
- PDF وNotebook بعد نجاح Prototype.
- Ink أساسي وAutosave وRecovery.
- Lecture Capture وCloseout.
- علامة «ما فهمت» وحفظ سياقها.
- شرح AI اختياري محدود بالمصادر.
- Project/Assignment Lite.
- Professor Feedback الأساسي.
- Drawing Coach Lite.
- بحث محلي أساسي.
- Full Export/Restore.
- Backup واضح الحالة.

### لا يمنع الإطلاق

- كل حزم مواد السنة الأولى المتخصصة بعمقها النهائي.
- Professor Intelligence المتقدم.
- AI Council.
- Full Sync.
- Visual Intelligence المتقدم.
- Desktop Companion.
- BIM/CAD.

## 4. النطاق المقترح لـYear-One Complete

- حزم جميع مواد السنة الأولى.
- Assessment Plan وGrade Control.
- Exam Mastery وProblem/Error Notebook.
- Drawing Coach بمسارات السنة الأولى.
- Assignment-based training.
- Skills & Evidence.
- Experience Memory.
- Portfolio Capture.
- Practice الأساسي للورش ومواد البناء.
- Early Warning وRecovery Mode.
- Submission Quality Gate.
- تحسينات Windows والهاتف.
- Sync فقط عند نجاح الاختبارات.

## 5. بوابات التنفيذ

### Gate P0 — الجهاز

- الطراز وإصدار النظام والقلم مثبتة.
- تثبيت التطبيق التجريبي ممكن.

### Gate P1 — القلم وPDF

- latency مقبول عمليًا.
- لا strokes عرضية من الكف ضمن اختبار القبول.
- الإحداثيات ثابتة عبر zoom/rotation.
- PDF كبير لا يسبب crash متكررًا.

### Gate P2 — سلامة البيانات

- لا فقدان بعد Force Kill.
- Backup وRestore ناجحان.
- امتلاء التخزين لا ينتج نجاحًا كاذبًا.

### Gate P3 — University Starter Pilot

- استخدام مادة حقيقية وواجب رسم حقيقي.
- Capture أسرع من التنظيم اليدوي.
- Today لا يزدحم.
- التطبيق يوفر وقتًا أكثر مما يستهلك.

### Gate P4 — توسعة السنة الأولى

- لا أخطاء حرجة مفتوحة.
- بيانات الاستخدام توضح الحاجة الفعلية.
- كل حزمة جديدة تملك Acceptance Criteria ومصدر محتوى.

## 6. القرار المطلوب

اعتماد الفصل التالي:

> Studio5 Core دائم لخمس سنوات. نبني أولًا University Starter مستقرة، ثم نكمل Year-One Complete خلال السنة الأولى. لا تُحذف أي وظيفة من الرؤية، لكن لا تصبح كل الوظائف شرطًا لبدء الجامعة.
