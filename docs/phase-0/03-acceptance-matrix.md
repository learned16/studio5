## بيانات الاختبار المطلوبة

- PDF صغير نصي.
- PDF ممسوح ضوئيًا متوسط.
- PDF معماري كبير الصفحات/الصور.
- ملف PDF تالف.
- ملف محمي أو غير مدعوم.
- جلسة strokes قصيرة وكثيفة وطويلة.
- حزمة Export سليمة وأخرى معدلة.
- أسماء عربية وإنجليزية ومتداخلة.

## أرقام تحتاج Freeze بعد القياس

- الحد المقبول لتأخر الحبر.
- نافذة الفقد القصوى بعد crash.
- الحجم/عدد الصفحات الذي يمثل PDF كبيرًا.
- زمن فتح التطبيق وToday.
- مدة الاحتفاظ بسلة المحذوفات.
- الحد الأدنى للمساحة الحرة قبل الاستيراد/الاستعادة.
