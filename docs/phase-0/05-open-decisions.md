# Studio5 — القرارات المفتوحة

**ملاحظة:** لا يلزم حسم كل التفاصيل الآن. عناصر `Blocker` فقط تمنع Freeze أو Prototype.

## Blockers قبل مراجعة المرحلة صفر

### O-001 — ملف السلطة الأصلي

**المطلوب:** إضافة ملف `01-Studio5_Year_One_Work_Handoff_AR-1.pdf` إلى المشروع.  
**السبب:** السياق المنقول لا يضمن احتواء كل القرارات والقيود.

## Blockers قبل Prototype الجهاز

### O-002 — الجهاز المرجعي

نحتاج:

- طراز MatePad الدقيق.
- إصدار HarmonyOS/Android.
- طراز القلم.
- المتصفح المتاح وإمكانية تثبيت APK/PWA.

**الافتراضي المقترح:** الـMatePad الذي سيستخدم يوميًا هو جهاز القبول الرسمي.

### O-003 — تعريف نجاح القلم

**القرار المطلوب:** اعتماد معيار ذاتي + قياس تقني، لأن رقم latency وحده لا يضمن إحساسًا جيدًا.

**الافتراضي المقترح:** اختبار رسم متكرر على الجهاز، مع عدم وجود فقد strokes أو انزياح، ثم تجميد أرقام الأداء من أفضل build مستقر.

## Blockers قبل Freeze التنفيذ

### O-004 — حد نسخة الدخول

هل المزامنة الكاملة وحل التعارضات شرطان قبل دخول الجامعة؟

**المقترح:** لا. Starter تحتوي Full Export/Restore وBackup؛ المزامنة الكاملة تُنجز في دفعة السنة الأولى التالية.

### O-005 — وجهة Backup

يلزم تحديد هل النسخة الأولى:

- حزمة محلية ينسخها المستخدم إلى وجهته.
- Backup إلى مزود سحابي محدد.
- الاثنان.

**المقترح:** Full Export محلي إلزامي، ثم مزود سحابي واحد فقط بعد إثبات الاستعادة.

### O-006 — معنى الهاتف وWindows

**المقترح:** لا تكافؤ كامل. MatePad للرسم، Windows للتنظيم والاستعادة، الهاتف للمتابعة والالتقاط.

## قرارات مهمة لا تمنع Prototype

### O-007 — مدة سلة المحذوفات

**المقترح:** 30 يومًا، مع حذف نهائي يدوي وتحذير واضح.

### O-008 — قوالب Notebook الأولى

**المقترح:** Blank، Grid، Dot فقط. تُضاف القوالب المعمارية بعد معرفة الاحتياج اليومي.

### O-009 — تمارين Drawing Coach الأولى

**المقترح:** خطوط مستقيمة، توازٍ، أشكال مغلقة، منظور نقطة واحدة، ومنظور نقطتين.

### O-010 — اللغة

**المقترح:** واجهة عربية RTL مع إبقاء المصطلحات التقنية الضرورية واضحة، وتصميم البيانات لقبول العربية والإنجليزية. لا تؤجل بنية الترجمة لكن لا يلزم إطلاق ترجمة كاملة منذ أول build.

### O-011 — الحساب

**المقترح:** لا يحتاج الاستخدام المحلي إلى حساب. الحساب مطلوب فقط عند تفعيل خدمة سحابية.

## قرارات مصالحة النطاق

### O-012 — تعريف نسخة ما قبل الجامعة

المخطط الأساسي الموسع يطلب جميع مواد السنة الأولى، وDrawing Coach، وUnderstanding Rescue، وProject Lite، والدرجات والاختبارات. مسودة Starter السابقة أضيق.

**المقترح:** نفصل بين:

- `University Starter`: نسخة يومية صغيرة ومستقرة تبدأ بها الجامعة.
- `Year-One Complete`: اكتمال حزم مواد السنة الأولى خلال السنة.

لا نحذف أي وظيفة؛ نحدد فقط بوابة إطلاقها.

### O-013 — الذكاء داخل University Starter

**المقترح:** تسجيل «ما فهمت» وسياقه يعمل Offline دائماً. الشرح الذكي يكون اختياريًا ومتصلًا بالمصادر، ولا يعطل التدفق إذا لم يوجد اتصال أو رصيد.

### O-014 — Drawing Coach قبل الجامعة

**المقترح:** يدخل `Drawing Coach Lite` فقط بعد نجاح Prototype القلم. التقييم يبدأ بالقياسات الهندسية القابلة للإثبات، بينما النقد الفني المتقدم يتأجل دون حذف.

### O-015 — تعدد الأجهزة

**المقترح:** نثبت تكافؤ البيانات والتدفقات الأساسية، لكن لا نشترط محرر Ink كاملًا على الهاتف والويب في أول إصدار.

## طريقة الرد المختصرة

يمكن لمالك المشروع اعتماد المقترحات دفعة واحدة بعبارة:

> اعتمد الافتراضات المقترحة مؤقتًا، واعتبر MatePad جهازي هو جهاز القبول، والمزامنة الكاملة بعد Starter.

تبقى إضافة ملف التسليم الأصلي مطلوبة قبل Freeze النهائي حتى لو اعتُمدت المقترحات.
