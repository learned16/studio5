# Studio5 — Decision Ledger

**الحالة:** Draft  
**قاعدة السجل:** لا يُحذف القرار القديم؛ عند تغييره يُضاف قرار جديد يذكر ما الذي استبدله ولماذا.

## حالات القرار

- `Proposed`: مقترح ينتظر التحقق أو الموافقة.
- `Accepted`: معتمد.
- `Superseded`: استُبدل بقرار أحدث.
- `Rejected`: رُفض مع توثيق السبب.

## افتراضات تحتاج تحققًا من المصدر الأصلي

- MatePad هو الجهاز الأساسي للرسم اليومي.
- Windows والهاتف ضمن نطاق السنة الأولى لكن بأدوار غير متطابقة.
- مدة Starter المستهدفة 12–14 أسبوعًا، والكمال الأوسع 16–18 أسبوعًا.
- السقف التشغيلي السحابي يقارب 100 دولار شهريًا.
- لا توجد حاجة إلى OpenAI API داخل تشغيل النسخة الأولى.
