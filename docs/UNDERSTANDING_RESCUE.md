# Understanding Rescue

## الهدف

تحويل علامة «ما فهمت» من ملاحظة منسية إلى مسار تعلم قصير موثق بالمادة والمحاضرة والصفحة والمصدر.

## تدفق السنة الأولى

1. Capture: المستخدم يحدد نصاً/صفحة/رسم أو يكتب سبب عدم الفهم.
2. Diagnose: مفهوم، قانون، رمز، خطوة، حساب، أو أساس سابق.
3. Explain: شرح مختصر مناسب للمشكلة؛ يعمل محلياً عندما لا يحتاج AI.
4. Practice: مثال أو سؤال تحقق أو تطبيق قصير.
5. Verify: فهم ذاتي أو إجابة/محاولة.
6. Escalate: إنشاء سؤال واضح للأستاذ إن بقيت الفجوة.
7. Closeout: يتحول إلى مهمة أو مراجعة أو عنصر Inbox مرتبط.

## الحدود

لا يوجد RAG واسع أو AI Coach كامل في هذه النسخة. واجهة المزود تبقى قابلة للتبديل، وفشل AI لا يمنع التقاط الفجوة أو الدراسة المحلية.

## مصدر وثقة

كل شرح أو اقتراح يخزن مصدره وحالته وثقته؛ لا يحول رأياً أو انطباعاً إلى قاعدة عامة بلا مصدر.
