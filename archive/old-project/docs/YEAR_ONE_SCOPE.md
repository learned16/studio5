# Year One Scope

## داخل التنفيذ

| المجال | النتيجة المطلوبة |
|---|---|
| Today | محاضرات، مهام، آخر ملف، مراجعات مستحقة وتنبيهات قابلة للتنفيذ |
| Study | مواد ومحاضرات وPDF ودفاتر وملاحظات وبحث ومفضلة وحديثة |
| Files | رفع وتصنيف، اقتراح مادة، Hash للتكرار، أصل ثابت، Versions وPreview |
| Notebook/Ink | قوالب أبيض/مسطر/مربعات/نقاط/isometric/engineering، قلم، حفظ واستعادة |
| Lecture flow | Capture خفيف: ما فهمت، مهم، تكليف، سؤال للأستاذ، ملاحظة أستاذ؛ ثم Closeout منظم |
| Tasks | يدوية أو مقترحة، حالة وأولوية وموعد وربط بالسياق |
| Reliability | Offline، Backup/Restore/Export، حالة مزامنة مستقبلية واضحة، Privacy |
| Drawing Coach Lite | تمارين ومحاولات وOverlay وقياسات صادقة وتقدم |

## خارج التنفيذ

لا يتم تنفيذ السنوات 2-5 أو AI Council أو التحكم بالكمبيوتر أو Desktop Companion أو Revit/AutoCAD/BIM أو مزامنة متعددة الأجهزة معقدة.

## قاعدة التوسع

تضاف السنوات القادمة كـSubject Profiles وCapability Packs وFeature Flags وMigrations. تبقى ملفات ومحاضرات ومهام ومحاولات السنة الأولى مرتبطة بمعرفاتها الأصلية.
