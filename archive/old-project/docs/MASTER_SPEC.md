# Studio5 Year One Master Specification

## الهدف

Studio5 حلقة عمل شخصية طويلة الأمد للدراسة والرسم والمشاريع:

`Capture -> Link -> Remember -> Warn -> Apply -> Learn`

النسخة الأولى تخدم طالباً واحداً في السنة الأولى. النجاح يعني استعمال يومي موثوق، لا عرض ميزات كثيرة.

## Must Have

- حساب وملف مستخدم واحد.
- Academic Year وSemester وSubject بمعرفات مستقرة.
- جدول أسبوعي، محاضرات، Today، مهام، Calendar أساسي.
- مواد ومحاضرات وملفات وPDF وNotebooks وLecture Capture وCloseout.
- Ink بالقلم مع Autosave واستعادة بعد الإغلاق/التعطل.
- ملفات أصلية غير قابلة للتعديل الصامت، Hash، كشف تكرار، سجل نسخ.
- Offline-first، بحث محلي، Favorites وRecent وUnified Inbox.
- Backup وRestore وFull Export وPrivacy/Lock وإعداد مكان التخزين.
- Drawing Coach Lite.

## مبادئ غير وظيفية

- الدراسة الأساسية تعمل دون AI أو شبكة.
- فشل Sync أو AI أو مزود تخزين لا يسقط البيانات المحلية.
- كل تغيير Schema يملك Migration مختبرة ومسار Recovery.
- لا تضيع strokes؛ يحتفظ النظام بـ raw strokes وpreview ونتيجة التحليل.
- RTL، تباين جيد، Touch targets مناسبة، وسرعة ملحوظة على MatePad.

## خارج النطاق

AI Coach كامل، RAG واسع، spaced repetition متقدم، Professor Intelligence كامل، دفتر موقع متقدم، plugins للبرامج، Desktop Companion، AI Council، Portfolio تلقائي، ومحتوى السنوات 2-5.

التفاصيل وقبول الميزة في الملفات المتخصصة.
