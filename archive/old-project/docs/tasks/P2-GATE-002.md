# P2-GATE-002 - Ink Revision History UI

## الهدف

إظهار نسخ الرسم المحفوظة داخل واجهة Notebook الحالية بدل عرض عددها فقط، مع معاينة آمنة واستعادة لا تفقد المسودة الحالية.

لا يتغير Core schema ولا تحذف أو تعدل أي Revision محفوظة.

## داخل النطاق

- زر واضح بعنوان «النسخ».
- قائمة Revisions مرتبة من الأحدث إلى الأقدم.
- عرض رقم النسخة، وقت حفظها، وعدد الخطوط والنقاط.
- معاينة Revision بوضع قراءة فقط.
- الرجوع من المعاينة إلى المسودة كما كانت.
- استعادة Revision مع تثبيت المسودة الحالية أولاً كنسخة آمنة.
- تحديث عدد النسخ بعد الحفظ أو الاستعادة.
- عمل القائمة محلياً ومن دون شبكة.

## خارج النطاق

- حذف النسخ أو إعادة تسمية تاريخها.
- مزامنة النسخ سحابياً.
- PDF أو المواد أو الذكاء الاصطناعي.
- تعديل Schema أو Migration.

## معايير القبول

1. زر «النسخ» يفتح قائمة كل Revisions لنفس InkDocument.
2. القائمة تعرض الأحدث أولاً وبيانات مفهومة لكل نسخة.
3. المعاينة لا تسمح بالرسم ولا تغير Autosave.
4. «رجوع للرسم» يعيد المسودة الأصلية بلا فقد.
5. «استعادة هذه النسخة» يحفظ المسودة الحالية كRevision أولاً ثم يجعل النسخة المختارة هي المسودة الحالية.
6. إغلاق حوار النسخ لا يغير الرسم.
7. الاختبارات وLint وType Check وBuild تنجح.
8. تنشر النتيجة على موقع Studio5 الحالي من دون إنشاء موقع جديد.

## Rollback

إزالة واجهة قائمة النسخ وواجهتي `listRevisions/loadRevision` فقط. تبقى كل Revisions وبيانات IndexedDB كما هي ولا يجري حذف أي بيانات.
